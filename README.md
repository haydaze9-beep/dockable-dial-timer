# Dial Timer

A floating dial timer for Windows. Drag the ring to set minutes, drag the
center to move it, and it docks to screen corners and edges.
this is made with claude

## Download

Go to the [Releases page](../../releases/latest) and choose one:

- **Setup** (recommended): installs the app, supports "Start with Windows".
- **Portable**: a single file, no installation needed.

> Windows may show "Windows protected your PC" because the app isn't
> code-signed. Click **More info**, then **Run anyway**.

## Controls

- **Drag the center** to move the dial. Release near an edge or corner to dock.
- **Drag the ring** to set the minutes (1 to 60).
- **Space** start/pause, **R** reset, **Up/Down** change minutes.
- **Right-click** the dial or the tray icon for the menu.

## Build from source

    npm install
    npm start
    npm run dist
